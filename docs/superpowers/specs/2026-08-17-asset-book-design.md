# 个人资产记账 PWA 产品方案

## 1. 产品定位

一句话定位：**个人资产盘点工具——只记"每个账户现在有多少钱"，自动算总资产，看得到资产增长曲线。**

- 形态：PWA（网页应用添加到 iPhone 主屏幕），部署于 GitHub Pages，与"刷券代拍记账本"同模式
- 用户：单用户自用，无注册登录
- 成本约束：零付费、零签名折腾、零服务器运维

**明确不做**（边界）：

| 不做的功能 | 原因 |
|-----------|------|
| 负债 / 信用卡 | 用户明确不需要 |
| 收入支出流水记账 | 记账负担重，与"资产快照"定位冲突 |
| 多币种 | 仅人民币场景 |
| 多设备实时同步 / 服务端 | 零成本约束；跨设备靠 Gist 备份恢复 |

## 2. 使用场景

1. **日常随手更新**：某个账户余额变了（发工资、转账、理财到账），打开 App 点该账户，输入新余额，10 秒完成。
2. **每月集中盘点**：月底进入"盘点模式"，逐个账户过一遍更新余额，结束后看到本月总资产变化。
3. **回顾增长**：打开趋势页，看近 3 个月 / 1 年的净资产曲线，确认资产健康度。

## 3. 功能需求（V1）

### 3.1 账户管理

- 添加 / 编辑 / 归档账户（归档不删除历史数据，不计入总资产，可恢复）
- 账户属性：名称、图标（预置：现金、银行、支付宝、微信、公积金、黄金、投资等一组常用图标）、颜色、所属分组、排序
- 分组：默认提供「现金、银行卡、支付平台、公积金、投资」，支持自定义增删改和排序；列表中分组可折叠，显示分组小计

### 3.2 余额更新与快照

- 点击账户 → 弹出数字键盘输入新余额 → 保存即生成一条带时间戳的快照记录
- 同一天多次更新均保留快照，趋势图取每日最后一条
- 快照可查看、可删除（删错余额时回退用）

### 3.3 盘点模式

- 首页「开始盘点」按钮进入，按分组顺序逐个账户展示：上次余额 + 新余额输入框，可跳过
- 盘点结束展示小结：本次总资产、较上次盘点变化金额与幅度

### 3.4 资产总览（首页）

- 顶部大数字卡片：总资产（= 所有未归档账户最新余额之和）
- 分组账户列表：每个账户显示图标、名称、当前余额、最后更新时间；超过 30 天未更新的账户标灰提醒
- 右上角小眼睛：一键隐藏 / 显示所有金额（隐藏状态持久记忆）
- 备份状态角标：已备份 / 待备份 / 备份失败

### 3.5 趋势图

- 总资产折线图，时间范围：近 1 月 / 3 月 / 1 年 / 全部
- 区间头部显示：期初 → 期末金额、涨跌额、涨跌幅
- 支持下钻查看单个账户的余额变化曲线与快照明细列表

### 3.6 数据备份与恢复

**自动备份（主）— GitHub 私有 Gist**

- 设置页一次性粘贴 GitHub Token（fine-grained，仅 gist 权限），App 自动创建一个私有 Gist 作为备份仓
- 数据每次变更后自动静默推送（防抖合并，避免频繁请求）；失败自动重试，首页角标提示状态
- 可选设置加密口令：上传前用口令 AES-GCM 加密，Gist 中仅存密文
- 恢复流程：新设备 / 重装后，设置页粘贴 Token（+ 口令）→ 拉取 Gist → 一键恢复全部数据

**手动备份（兜底）**

- 一键导出 JSON 到文件 App（可存 iCloud 云盘）、一键导入恢复
- 未配置 Gist 且距上次导出超过 30 天时，首页轻提醒

### 3.7 设置页

账户与分组管理、Gist 备份配置（Token / 加密口令 / 立即备份 / 从备份恢复）、导出 / 导入 JSON、关于（版本号、数据统计）。

## 4. 页面结构

```
底部 Tab：
├── 资产（首页）：总资产卡片 / 分组账户列表 / 盘点按钮 / 眼睛 / 备份角标
└── 趋势：折线图 / 时间范围切换 / 账户下钻

首页左上角 ☰ → 设置页
```

交互风格对齐参考截图：卡片式布局、总资产大数字居中、分组折叠列表、底部大圆加号（添加账户）。

## 5. 数据模型

```
Group    分组:  id / 名称 / 排序
Account  账户:  id / 名称 / groupId / 图标 / 颜色 / 排序 / 是否归档 / 创建时间
Snapshot 快照:  id / accountId / 余额 / 记录时间
Settings 设置:  金额隐藏状态 / gistToken / gistId / 加密口令 / 上次备份时间与状态 / 上次导出时间
```

派生规则（不冗余存储）：

- 账户当前余额 = 该账户最新一条快照的余额
- 总资产 = 所有未归档账户当前余额之和
- 趋势图数据点 = 每日各账户最后一条快照聚合

## 6. 技术方案

| 项 | 选型 | 说明 |
|----|------|------|
| 部署 | GitHub Pages | 代码仓公开（仓库内不含任何个人数据），零成本 |
| 文件构成 | index.html + styles.css + core.js + ui.js + gist.js + manifest.json + sw.js + 图标 | 无构建静态多文件；核心逻辑独立 core.js 便于单元测试 |
| 本地存储 | localStorage（单 key 存 JSON） | 数十账户 × 数千快照量级足够；每次操作即时落盘 |
| 图表 | 纯 SVG 手绘折线图 | 不引外部库，保证离线与加载速度 |
| 离线 | Service Worker cache-first | 断网可完整使用（除 Gist 备份） |
| 云备份 | GitHub Gist API（fetch + Token） | Token 仅存本机 localStorage |
| 加密 | WebCrypto：PBKDF2 派生密钥 + AES-GCM | 口令不上传，仅本机保存 |
| 更新机制 | push 后 SW 检测新版本静默更新 | 迭代无需用户操作 |

## 7. 迭代规划

| 版本 | 内容 |
|------|------|
| V1 | 第 3 节全部功能（账户 / 快照 / 盘点 / 总览 / 趋势 / Gist 自动备份 / 手动导出） |
| V1.1（可选） | WebAuthn 调用 FaceID 做打开锁；快照备注（如"发年终奖"）；趋势图月度涨跌标注 |
| 暂不规划 | 多币种、流水记账、负债——除非定位变化 |

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 删除主屏图标导致本地数据清空 | Gist 自动备份为主 + 手动导出兜底；恢复流程 1 分钟内完成 |
| GitHub Token 泄露 | 使用 fine-grained token 且仅授予 gist 权限；Token 只存本机 |
| 网络波动导致备份失败 | 本地待备份队列 + 自动重试 + 首页状态角标显式提醒 |
| Gist 内容隐私 | 私有 Gist + 可选口令加密（密文存储） |
| iOS 版本更新导致 PWA 行为变化 | 主屏 Web App 独立存储容器不受 Safari 7 天清理策略影响；备份机制兜底 |

## 9. 验收标准（V1）

1. iPhone Safari 添加到主屏幕后，全屏打开、离线可用、外观接近原生 App
2. 完成一次完整盘点（≥5 个账户）耗时不超过 2 分钟
3. 余额更新后 1 分钟内自动完成 Gist 备份，首页角标显示"已备份"
4. 删除主屏图标 → 重新添加 → 粘贴 Token 恢复，数据 100% 找回
5. 趋势图正确反映历史快照，区间涨跌计算准确
